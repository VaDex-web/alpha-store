# Alpha Store — сайт магазина электроники

Концепт-редизайн сайта магазина электроники Alpha Store в Ростове-на-Дону: каталог из 150 предложений, отдельная страница для каждой модели и выбор варианта по памяти, SIM и цвету.

**Демо:** https://vadex-web.github.io/alpha-store/

## Что внутри

- **Каталог** — 150 позиций из каталога магазина собраны в 37 моделей; поиск, фильтры по категории и бренду, сортировка по цене
- **Страница товара** (`product.html?m=…`) — выбор памяти, типа SIM и цвета с мгновенным пересчётом цены, таблица всех вариантов, похожие модели, своя ссылка на каждый вариант
- **Иллюстрации вместо отсутствующих фото** — телефон рисуется в SVG в цвете выбранного варианта, расположение камер повторяет реальную модель
- **Заказ через существующую корзину** — кнопка «Оформить заказ» ведёт на товар в каталоге магазина на платформе Яндекс Бизнес, рабочие функции не подменяются макетом
- Условия покупки, отзывы с Яндекс Карт, фото магазина с просмотром, карта и контакты
- Адаптивная вёрстка, семантическая разметка, статус «Открыто / Закрыто» по московскому времени

## Стек

HTML, CSS, Vanilla JavaScript, SVG. Без сборки и зависимостей.

| Файл | Назначение |
|---|---|
| `index.html` | главная страница и каталог |
| `product.html` | страница товара |
| `data.js` | данные каталога |
| `common.js` | общая логика: группировка моделей, иллюстрации, ссылки |
| `style.css` | стили |

## Запуск

Открыть `index.html` в браузере или включить GitHub Pages для ветки `main`.
